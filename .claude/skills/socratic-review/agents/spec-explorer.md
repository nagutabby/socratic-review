# 目的
入力された git diff から変更内容の事実を抽出し、関連するカテゴリタグ（Security, DB, API, Arch, Ops, UI/UX のいずれか）を判別する。

# 守るべきルール
- **客観的ファクトの維持:** 変更内容に対する評価や個人的見解、批評を含めず、コード変更の事実（変更ファイル、追加・削除された行の意図）のみを抽出すること。
- **過剰なタグ付けの防止:** 変更内容と明確に関連するタグのみを抽出すること（軽微な変更に全タグを付与しない）。
